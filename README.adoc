A comprehensive Machine Learning and MLOps engineering system designed for credit risk assessment and default prediction. This project integrates financial data processing, classification model fine-tuning, and a robust MLOps architecture for deployment and continuous monitoring.

---

== 📌 Project Overview

The primary objective of this project is to predict a customer's probability of default based on socio-economic and financial features.

=== Key Features
* **Machine Learning Pipeline:** Data preprocessing, feature engineering, class imbalance management, and scoring model calibration.
* **Fine-Tuning:** Hyperparameter optimization for classification models (Scikit-learn / XGBoost / LightGBM) to maximize Recall and ROC-AUC metrics.
* **Serving API (In Progress):** Model serving via a high-performance **FastAPI** web service.
* **User Interface (Upcoming):** Interactive **Streamlit** dashboard for manual feature input and real-time scoring simulation.
* **Monitoring & Observability (In Progress):** Data drift and performance monitoring in production using **Prometheus** and **Grafana**.

== 🚀 Installation & Setup

=== 1. Clone the Repository
[source,bash]
----
git clone https://github.com/Madeinheaven0/default-card-risk-detection.git
cd credit-risk-detection
----

=== 2. Install Dependencies with `pyproject.toml`

==== Option A: Using `pip` (Standard)
[source,bash]
----
python -m venv venv
source venv/bin/activate  # On Linux/macOS
# venv\Scripts\activate     # On Windows
pip install .
----

==== Option B: Using `Poetry`
[source,bash]
----
poetry install
poetry shell
----

==== Option C: Using `uv` (Ultra-fast)
[source,bash]
----
uv venv
source .venv/bin/activate
uv pip install .
----

=== 3. Run Mode Training
[source,bash]
----
python src/models/train.py
# Or with Poetry: poetry run python src/train_and_tune.py
----
